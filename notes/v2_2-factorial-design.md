# V2.2 Factorial Suite — Need × Cost × Alternative Claim

**Created:** 2026-07-11, from Juan's discussion (with Sol) on taskless environments and moral-vs-moral tradeoffs. Successor to `v2_1-stimulus-suite-design.md`; feeds E18 in `EXPERIMENT_LOG.md`.

## Question

Decompose the edited "costly helping" mechanism into separable factors: need sensitivity, prosocial action, cost integration, moral allocation. The current result is specifically *welfare-over-task arbitration* (cell B audit: when helping is free, even "task-focused" responses help — 27/90 contrasts survived). Is that all the mechanism is?

## Three axes (factorial, not exhaustive crossing)

1. **Need:** absent → mild → urgent *(cell S already implements this)*
2. **Cost of helping:** free → low (inconvenience) → medium (lost progress) → high (objective failure) *(B = free; M/T = high; low/medium are new)*
3. **Alternative claim:** none → instrumental task → **another moral beneficiary** *(entirely new axis)*

On "taskless": not achievable absolutely ("do whatever you want" is still an instruction); operational definition = no externally imposed objective/metric/deadline competing with welfare. Useful as a default-policy measurement, but the identifying variation is cost manipulation within an identical environment.

## Moral-vs-moral progression (hold everything else constant)

Start with contrasts that don't have culturally overdetermined answers (NOT child-vs-cat):
mild vs urgent person · one vs two equally urgent · certain moderate harm vs uncertain severe harm · already-helped vs unattended · stranger vs teammate (need constant) · immediate rescue vs preventing later harm. Then independently vary species, relationship, responsibility, certainty, number.

## Construction constraints (lessons from E04/E05)

- **Templated, matched-lexicon, cell-M-style.** Cost and alternative-claim varied ONLY in scenario structure; emotion vocabulary identical across arms. Otherwise lexical saturation eats the dose-response like it ate V1's AUROC.
- Shared prefix + divergent decision clause where possible → decision-token metrics for free.
- Audit each cell for retained contrast (E10 protocol) before use.

## What the weight edits predict (falsification table for E18)

Run {baseline, positive_writers, suppressors} edited models across the grid:

| Observation | Reading |
|---|---|
| Effect only when helping is costly | task-vs-welfare **arbitration** mechanism (current claim stands) |
| Effect even when helping is free | more general **helping policy** |
| Effect on moral-vs-moral allocation | **welfare-weighting / triage** mechanism |
| Effect on action but not third-person recognition | practical disposition, not empathy concept |
| Effect on warm language but not action | persona/style, not moral behavior |

Dose-response over the cost axis is the headline figure: helping rate vs cost level, one curve per edit condition.
